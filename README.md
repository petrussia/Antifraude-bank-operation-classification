# Страж · Data Fusion Contest 2026

Учебный проект по прогнозированию неподтверждённых банковских операций.

## Загрузка данных

1. Войдите в ODS как участник соревнования. В разделе [Данные](https://ods.ai/competitions/data-fusion2026-guardian/dataset) нажмите правой кнопкой на название файла `train_labels.parquet` и скопируйте адрес ссылки.
2. Из каталога проекта запустите `python download_data.py` (Python 3, только стандартная библиотека).
3. Вставьте ссылку и нажмите Enter. Скрипт скачает 10 файлов в папку `data/` рядом со скриптом. Понадобится около 4,4 ГБ свободного места.

В комплект входят три части истории для предобучения, три части обучающей выборки, обучающие метки, предтестовая история, тестовые операции и пример посылки. При повторном запуске скрипт пропускает файлы ожидаемого размера.

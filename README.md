# Страж · Data Fusion Contest 2026

Учебный проект по прогнозированию неподтверждённых банковских операций.

## Загрузка данных

Из каталога проекта запустите:

```sh
python download_data.py
```

Скрипт скачает все 10 файлов по прямым ссылкам в папку `data/` рядом со скриптом. Понадобятся Python 3 и около 4,4 ГБ свободного места. [Описание датасета на ODS](https://ods.ai/competitions/data-fusion2026-guardian/dataset) · [Правила соревнования](https://storage.yandexcloud.net/ds-ods/files/data/docs/competitions/DataFusion2026/Rules_Data_Fusion_Contest_2026.pdf)

В комплект входят три части истории для предобучения, три части обучающей выборки, обучающие метки, предтестовая история, тестовые операции и пример посылки. При повторном запуске скрипт пропускает файлы ожидаемого размера.
